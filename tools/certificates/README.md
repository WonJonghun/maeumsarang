# PC 접속 인증서 등록

현재 주소 `https://192.168.90.20:8081`에 사용하는 자체 서명 인증서를 Windows에 신뢰 등록합니다. 서버 재시작은 필요하지 않습니다.

## 상단바에서 설치

1. 직원이 자신의 PC에서 인트라넷에 로그인합니다.
2. PC 상단바의 조직도 아이콘 오른쪽에 있는 방패 아이콘 **인증서 설치**를 누릅니다.
3. 다운로드 목록에서 `install-intranet-certificate.cmd`를 실행합니다. 공개 인증서를 포함하므로 `.cer`를 따로 받을 필요가 없습니다.
4. 인증서 보안 경고가 나타나면 아래 지문을 확인하고 설치합니다.
5. 브라우저를 완전히 종료한 뒤 다시 접속합니다.

웹페이지는 다운로드한 프로그램을 자동 실행하거나 Windows의 인증서 신뢰 설정을 직접 바꿀 수 없습니다. 다운로드 후 실행은 직원이 한 번 해야 합니다. Edge나 Windows 정책에서 다운로드·실행을 차단한 경우 전산 담당자가 인증서를 배포합니다.

버튼의 설치 파일은 `src/main/resources/static/pc/certificates/install-intranet-certificate.cmd`입니다. 서버 인증서를 교체하면 이 파일에 포함된 공개 인증서와 지문도 새 인증서로 변경해야 합니다.

## 직원 PC에서 설치

1. 아래 두 파일을 같은 폴더로 복사합니다.
   - `intranet-192.168.90.20.cer`
   - `install-current-user.cmd`
2. 직원이 평소 사용하는 Windows 계정으로 `install-current-user.cmd`를 더블클릭합니다. 관리자 권한으로 실행할 필요가 없습니다.
3. Windows 인증서 보안 경고가 나타나면 아래 인증서 지문과 일치하는지 확인하고 설치합니다.
4. Edge 또는 Chrome 창을 모두 닫은 뒤 `https://192.168.90.20:8081`에 다시 접속합니다. 브라우저가 백그라운드에 남아 있다면 작업 관리자에서 종료하거나 Windows에서 로그아웃 후 다시 로그인합니다.

스크립트는 파일의 SHA-256을 확인한 뒤 `현재 사용자 → 신뢰할 수 있는 루트 인증 기관`에 이 인증서만 등록합니다. 기존 인증서와 서버 설정은 변경하지 않습니다. PC 또는 Windows 계정이 다르면 각각 설치해야 합니다. 회사 정책으로 사용자 인증서 등록이 제한된 PC는 전산 담당자가 배포해야 합니다.

## 스크립트 실행이 차단된 경우

1. `.cer` 파일을 더블클릭하고 **인증서 설치**를 누릅니다.
2. 저장소 위치는 **현재 사용자**를 선택합니다.
3. **모든 인증서를 다음 저장소에 저장**을 선택합니다.
4. **신뢰할 수 있는 루트 인증 기관**을 선택하고 마칩니다.
5. 브라우저를 완전히 종료한 뒤 다시 접속합니다.

인증서가 등록된 뒤에도 경고가 남으면 인증서 상세의 오류를 확인합니다. 서버 인증서를 교체했거나 접속 IP가 달라진 경우 현재 파일로는 해결되지 않습니다.

## 인증서 정보

- 접속 IP(SAN): `192.168.90.20`
- 유효기간: `2025-12-05` ~ `2035-12-03`
- SHA-1 지문: `49A2ED94EFD6047DA455190567BFBB41C308D2B1`
- SHA-256 지문 및 파일 해시: `EEA48CB694C2F3AB59AB0A54A3CB536082FCA4E680FD70E3EF850918B9779831`
- 공개 인증서만 포함하며 개인 키와 비밀번호는 포함하지 않습니다.

직원 PC에 배포할 파일은 위 `.cer`와 `.cmd`입니다. 서버의 `src/main/resources/ssl/intranet.p12`는 개인 키가 들어 있으므로 배포하지 않습니다.

## 등록 취소

해당 Windows 계정의 PowerShell에서 다음 명령을 실행하면 이 인증서의 신뢰 등록만 제거합니다.

```powershell
Remove-Item -LiteralPath 'Cert:\CurrentUser\Root\49A2ED94EFD6047DA455190567BFBB41C308D2B1'
```

## 중앙 배포

Active Directory에서 PC를 관리한다면 같은 `.cer`를 그룹 정책의 `컴퓨터 구성 → 정책 → Windows 설정 → 보안 설정 → 공개 키 정책 → 신뢰할 수 있는 루트 인증 기관`에 가져와 배포할 수 있습니다. PC별 수동 설치는 생략할 수 있습니다.
